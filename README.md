# FoodFlix

Interface responsiva inspirada em catálogos de streaming, com foco em conteúdos sobre gastronomia, cultura e alimentação.

## Stack

- HTML semântico
- CSS responsivo
- JavaScript com jQuery
- Owl Carousel 2

## Melhorias de UX/UI

- identidade visual própria para o FoodFlix
- hero editorial com hierarquia mais clara
- navegação mobile com menu acessível
- estados de foco e suporte a reduced motion
- carrossel responsivo com cards de maior contraste
- tipografia, spacing e tokens visuais consistentes
- melhor comportamento em desktop, tablet e mobile
- carregamento lazy das imagens do catálogo

## Execução

Abra `index.html` em um navegador ou publique via GitHub Pages.
